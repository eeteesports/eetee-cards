# Read this first

in the `eetee Card Collection` parent folder). It is the full, current
project handoff — architecture, environment variables, known issues,
in-progress work, and prioritized next steps for both this site and its
sibling `eetee-cards-app`. This file is intentionally just a pointer so
that pointer survives even if a session is opened directly inside this
repo rather than at the parent folder.
